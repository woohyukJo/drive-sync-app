개인정보처리방침

Drive Sync는 운영자 본인만 사용하는 개인용 OAuth 클라이언트입니다.

  • 요청 권한은 drive.file 하나로, 앱이 직접 만든 파일에만 접근합니다.
  • 저장되는 데이터는 기기에서 암호화된 뒤 사용자 본인의 Google Drive에만 올라갑니다.
  • 어떤 데이터도 운영자 서버나 제3자에게 전송, 판매, 공유하지 않습니다.
  • Google 사용자 데이터의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
  • 앱 연결을 해제하려면 Google 계정의 서드파티 액세스에서 권한을 삭제하면 됩니다.

Privacy Policy

Drive Sync is a personal OAuth client used only by its operator.

  • It requests only the drive.file scope and can access only files the app itself created.
  • Data is encrypted on the device before being uploaded to the user's own Google Drive.
  • No data is sent to, sold to, or shared with the operator's servers or any third party.
  • Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time from Google Account third-party access.
